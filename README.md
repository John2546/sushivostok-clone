# SushiVostok Clone

This repository contains a simple example website inspired by the design of the Sushi Vostok delivery service. It is **not** an exact copy of the original site; all text and images are placeholders.

The project demonstrates a basic layout with HTML, CSS, and JavaScript:

- `index.html` &mdash; homepage with sections for menu, order form, and contacts.
- `style.css` &mdash; simple styling for navigation, hero section, and content blocks.
- `script.js` &mdash; small script for scrolling and order form handling.

Feel free to modify the content, images, and styles to suit your own sushi delivery project.
